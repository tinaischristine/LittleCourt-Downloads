# 小朝会

小朝会是一款本地优先的 macOS 个人项目管理工作台。项目、任务、计划和执行记录保存在你自己的 Mac 上。打开即可使用，日常使用可以离线，无需注册或登录。应用不收集分析数据，也不上传私人项目。

支持项目、阶段、真实进度、这周、今天、随手记、回顾、执行记录及 JSON 备份。

| 版本 | 系统 | 架构 | 签名与公证 |
| --- | --- | --- | --- |
| v0.1.0 开发测试版 | macOS 14.0 或更新版本 | Universal（arm64 + x86_64） | ad-hoc 签名，未使用 Developer ID，未公证 |
